# 릴스 배경 음악

- 여기 있는 곡만 릴스에 쓴다. **상업적 사용이 허락된 무료 음원만** 넣는다 (예: Pixabay Music, 유튜브 오디오 보관함 '저작자 표시 필요 없음').
- 인스타 인기곡(앱 안 음악)·가요·드라마 OST 파일은 절대 넣지 않는다 (저작권 위반 → 소리 꺼짐·삭제·계정 정지).
- `tracks.json` 형식:
  `[{"file": "곡파일.mp3", "title": "곡 이름", "source": "Pixabay Music 주소", "license": "Pixabay Content License", "start": 0}]`
  - `start`: 곡에서 시작할 초 (도입부가 심심하면 후렴 시작 지점으로)
- 프로그램이 가장 오래 안 쓴 곡부터 돌려 쓴다. 곡이 하나도 없으면 직접 만든 배경음을 쓴다.
